# John Edward, portfolio

UI/UX portfolio: bskt, reDial and Alarm, reimagined.

A single static page (`index.html`) with GSAP scroll animation. No build step.

## Run locally
Open `index.html` in a browser, or serve the folder: `python3 -m http.server`.

## Publish
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Add a project
Copy one `<article class="project">` block inside `.work-grid` in `index.html`.
